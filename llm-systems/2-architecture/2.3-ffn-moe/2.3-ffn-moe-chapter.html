① 是什么：FFN、归一化与 MoE

直觉类比

如果 Attention 是"人与人之间的交流"，那 FFN 就是"每个人的大脑记忆库"——Attention 决定你关注谁，FFN 决定你从记忆里取出什么知识来回应。

归一化是"音量旋钮"，防止信号在层层传递中越来越大或越来越小。

MoE 则是"医院分诊台"：不是所有科室都处理每个病人，而是根据症状把病人路由到最相关的专家那里，节省资源。

FFN：Transformer 的知识存储器

在 Transformer 的每一层，信息流经两条路径：

FFN（Feed-Forward Network，前馈网络）是 Transformer 中唯一包含"知识"的模块。它的核心操作：

$$\text{FFN}(x) = \sigma(xW_1 + b_1) \cdot W_2 + b_2$$

其中 $W_1$ 将输入从 $d_{\text{model}}$ 维映射到 $d_{\text{ff}}$ 维（通常 $d_{\text{ff}} = 4 \times d_{\text{model}}$），$\sigma$ 是激活函数，$W_2$ 再投影回 $d_{\text{model}}$ 维。

产品视角

DDAgent 处理尽调报告时，Attention 找到"这家公司"与"尽调模板"的对应关系，而 FFN 里存储了"尽调领域的专业知识"——什么是关键财务指标、什么风险需要关注。FFN 越大，模型"懂"的领域知识越多。

归一化：训练稳定的守护者

深层网络中，每层的输出幅度如果不控制，60 层后信号可能放大 300 倍（$1.1^{60} \approx 304$）或衰减到零——梯度爆炸/消失。归一化的本质是：每一层结束后把信号"归零重整"，确保下一层收到的输入幅度稳定。

MoE：用更少的算力存更多的知识

MoE（Mixture of Experts，混合专家）的核心思想：不激活全部参数，只激活与当前输入相关的"专家"。一个 671B 总参数的模型，每次推理只激活 37B 参数——成本降低 18 倍，但知识容量不变。

Takeaway

FFN 是 Transformer 的"记忆库"，归一化是"稳定器"，MoE 是"分诊台"。三者组合让模型既能存大量知识（FFN 大），又能稳定训练（归一化），还能控制推理成本（MoE 稀疏激活）。

② 怎么实现：SwiGLU · RMSNorm · MoE 路由

2.1 SwiGLU：从开关到调光旋钮

激活函数的演进：ReLU（硬开关）→ GELU（平滑开关）→ SwiGLU（智能门控）。

ReLU：简单粗暴，负值归零，正值原样通过。

$$\text{ReLU}(x) = \max(0, x)$$

问题：梯度在 $x < 0$ 时恒为零——"死亡神经元"，一旦进入负区间永远无法恢复。

SwiGLU（2026 行业标准，LLaMA/Qwen/DeepSeek/Mistral 全部采用）：

$$\text{SwiGLU}(x) = (\text{Swish}(xW_1) \odot xW_3) \cdot W_2$$

其中 $\text{Swish}(x) = x \cdot \sigma(x)$，$\sigma$ 是 sigmoid 函数，$\odot$ 是逐元素乘法。

关键设计：$d_{\text{ff}}$ 从传统 $4d$ 调整为 $\frac{8}{3}d \approx 2.69d$（如 LLaMA: $d=4096 \to d_{\text{ff}}=11008$），保持总参数量与 ReLU FFN 相当，但效果更优。

直觉类比

ReLU 是"灯泡开关"——只有开和关。SwiGLU 是"调光旋钮"——不仅决定信息是否通过，还精细控制通过多少。这种乘法交互（门控 × 内容）让网络能学习"哪些特征组合重要"——类似 Attention 中 QK 乘积捕获交互的思路。

2.2 RMSNorm + Pre-Norm：轻量稳定方案

现代 LLM 的归一化标配：RMSNorm + Pre-Norm。

LayerNorm（原始 Transformer）：

$$\text{LN}(x) = \frac{x - \mu}{\sqrt{\sigma^2 + \epsilon}} \cdot \gamma + \beta$$

同时调整均值 $\mu$ 和方差 $\sigma^2$，需要两个可学习参数 $\gamma, \beta$。

RMSNorm（LLaMA/DeepSeek/Qwen 全部采用）：

$$\text{RMSNorm}(x) = \frac{x}{\sqrt{\frac{1}{d}\sum_{i=1}^d x_i^2 + \epsilon}} \cdot \gamma$$

省略均值中心化，只调整幅度。可学习参数只有 $\gamma$（无 $\beta$），计算更快，效果相当。

Pre-Norm vs Post-Norm：

位置公式优势劣势使用方
Pre-Norm$x + f(\text{Norm}(x))$梯度稳定，不需要 warm-up深层可能欠优化LLaMA/Qwen/DeepSeek（主流）
Post-Norm$\text{Norm}(x + f(x))$理论表达力更强需精心 warm-up，训练不稳原始 Transformer
Sandwich-NormNorm 在 Attention/FFN 前后各一个更稳定多一次 Norm 开销Gemma 2/3

2.3 MoE 路由机制

MoE 层将一个大型 FFN 替换为 $N$ 个小型 FFN（专家），通过 Router 动态选择每 token 激活哪 $K$ 个专家：

$$g(x) = \text{TopK}(\text{softmax}(x \cdot W_r + b))$$

$$\text{MoE}(x) = \sum_{i \in g(x)} g_i(x) \cdot E_i(x)$$

DeepSeek 的创新：共享专家 + 无辅助损失均衡

DeepSeek-V3/V4 引入 1 个"共享专家"（所有 token 必经）+ 256 个"路由专家"（每 token 激活 8 个）。共享专家处理通用知识（语法、常识），路由专家专注领域知识。

传统 MoE 用辅助损失（auxiliary loss）强制负载均衡，但会损害模型性能。DeepSeek-V3 改用偏置调整法：为每个专家维护一个可调偏置 $b_i$，在 TopK 选择时加入 $\rho + b$，动态调整负载，无需额外损失函数。

Takeaway

SwiGLU 的乘法门控创造特征交叉（类似 Attention 的 QK 乘积），RMSNorm 比 LayerNorm 省计算且效果相当，MoE 的 Router 做动态专家选择实现稀疏激活。2026 行业标配：SwiGLU + RMSNorm + Pre-Norm + MoE。

③ 为什么：设计取舍的第一性原理

3.1 为什么 FFN 是知识存储器？

从第一性原理看，Attention 是动态关联（token 之间建立连接），FFN 是静态记忆（从训练好的权重中提取知识）。这有一个经典的实证依据：

Geva et al. (2021) 发现 FFN 的每个神经元对应一个"语义模式"——$W_1$ 的每一行像一个"键"（key），匹配输入中的特定模式；$W_2$ 的每一列像一个"值"（value），输出对应的知识。

$$\text{FFN}(x) = \sum_{j=1}^{d_{\text{ff}}} \sigma(x \cdot w_{1j}) \cdot w_{2j}$$

每个 $w_{1j}$ 是一个"知识条目"：当输入匹配 $w_{1j}$（$\sigma$ 输出大），$w_{2j}$ 对应的"值"被激活——像极了 Key-Value 存储。

直觉类比

FFN 就像 DDAgent 的知识库（KBA）：$W_1$ 是"索引"（什么问题匹配什么知识），$W_2$ 是"内容"（匹配到后输出什么答案）。FFN 参数量越大 = 知识库条目越多。

3.2 为什么 SwiGLU 击败了 ReLU？

维度ReLUGELUSwiGLU
非线性能力弱（硬截断）中等（平滑）强（门控+平滑）
梯度稳定性死亡神经元较好非常好（无硬截断）
表达能力单路径单路径双路径交互（乘法门控）
参数量2 矩阵（$W_1, W_2$）2 矩阵3 矩阵（$W_1, W_2, W_3$）
困惑度基准略优显著优（-0.5~1.0 ppl）

核心原因：SwiGLU 的乘法交互 $\text{Swish}(xW_1) \odot xW_3$ 创建了特征交叉项 $x_j \times x_k$——这与 Attention 中 $QK^T$ 乘积捕获交互的逻辑一致。单路径激活（ReLU/GELU）只做加权和，特征之间不交互。

3.3 为什么 RMSNorm 替代了 LayerNorm？

RMSNorm 省掉了均值中心化（减 $\mu$），只做幅度归一化。为什么省这一步不影响效果？

因为 Transformer 中每个 token 的特征分布本身就没有明显的"偏移"（不像 CNN 有通道间的分布差异），均值中心化是冗余操作。省掉后：计算量减半、参数减半（无 $\beta$）、训练更稳定。

3.4 为什么 MoE 能用 1/18 的算力达到同级效果？

直觉：不是所有知识都需要同时激活。处理数学题时，不需要文学专家；处理中文时，不需要法语专家。

数学本质：Dense 模型每 token 激活全部 $P$ 个参数，MoE 模型每 token 只激活 $P/K_{\text{ratio}}$ 个参数（$K_{\text{ratio}}$ = 总参数/激活参数），但总知识容量仍然是 $P$。

DeepSeek-V4 Pro：1.6T 总参数 / 49B 激活参数 = 33× 稀疏比。知识容量等同 1.6T Dense 模型，但推理成本只有 49B 级别。

关键取舍

MoE 的代价：(1) 全部参数都要加载到显存，内存需求 = 总参数量（不是激活量）；(2) 负载不均衡风险——某些专家被过度使用，某些闲置；(3) 训练更复杂，需要路由均衡策略。这就是 DeepSeek-V3 创新无辅助损失均衡的原因。

Takeaway

FFN 是 Key-Value 知识库，SwiGLU 的乘法门控让知识提取更精准（特征交叉），RMSNorm 省掉冗余操作更高效，MoE 用"分诊台"思路解耦知识容量和计算成本——但代价是显存和训练复杂度。

⑤ 与产品：Agent 成本优化的架构基础

5.1 FFN 知识存储 → DDAgent 的"领域专家"

DDAgent 的 Dispatcher 架构本质上在做"人工 MoE"：不同子 Agent 就像不同专家，路由器（Dispatcher）根据尽调场景把请求分配到最相关的子 Agent。

类比映射：

MoE 概念DDAgent 对应本质
RouterDispatcher动态路由，匹配输入到最相关专家
共享专家通用尽调框架所有场景都需要的基础知识
路由专家子 Agent（银行/保险/证券）领域专用知识
Top-K 选择场景匹配每 token/请求只激活最相关的 K 个
负载均衡子 Agent 任务分配防止某些子 Agent 过载

5.2 MoE 稀疏激活 → Agent 推理成本优化

FxAgent 日均 250 次换汇咨询，如果每次都调用全量模型推理，成本不可控。MoE 的思路启示：

产品启示

轻量路由 + 按需激活：先轻量判断用户意图（Router），只对复杂查询调用重模型（路由专家），简单查询走轻模型或规则（共享专家）。FxAgent 的 98-99.75% AI 采纳率说明：大部分换汇咨询是标准化问题，不需要"全量专家"。

5.3 归一化 → Agent 输出稳定性

TRSAgent 处理售后邮件时，分类准确率 92.2% 但仍有误分类。归一化的启示：在 Agent 流水线中加入"归一化层"——每个环节结束后做质量校验（Gate），防止错误在后续步骤中被放大（类似梯度爆炸）。

Fitz 的 Harness 框架中，Gate 组件就是 Agent 的"归一化层"：每步行动后检查输出是否在合理范围内，超出则拦截重试。

Takeaway

MoE 的"稀疏激活"思想可以直接映射到 Agent 架构：DDAgent 的 Dispatcher 就是人工 Router，Harness 的 Gate 就是归一化层。理解了 FFN/MoE 的设计原理，就能更好地设计 Agent 的路由和成本优化策略。
